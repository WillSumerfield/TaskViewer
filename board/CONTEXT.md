# Board

The desktop views of the App's state: the Board and the Glance. Shared terms (Task, Session, statuses, lifecycle) are defined in the [root glossary](../CONTEXT.md).

## Language

**Board**:
The toggleable, read-only detail view of all visible Task trees, grouped by Project then tree, shown over current work and hidden on demand.
_Avoid_: Window, panel, dashboard

**Glance**:
The always-visible one-line summary in the desktop bar (or tray): the count of Sessions, plus Sessions Awaiting user and Blocked Tasks in Live trees when there are any.
_Avoid_: Widget, status, indicator
